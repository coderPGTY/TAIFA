# Спецификация языка SharkSharp

## Введение

SharkSharp — минималистичный императивный язык программирования общего назначения со строгой статической типизацией, разработанный для обучения основам построения компиляторов.

Ключевые особенности языка:
- Весь исходный код программы располагается в одном файле.
- Точкой входа является функция `main`.
- Строгая статическая типизация: в текущей итерации поддерживается только тип `int` (64-битные знаковые целые числа).
- Императивный, процедурный стиль программирования.
- Поддержка структурного программирования: последовательное выполнение инструкций в блоке.
- Ввод/вывод осуществляется через встроенные функции `print` и `readInt`.
- Поддержка арифметических операций, включая деление с остатком (`%`).
- Поддержка встроенных математических функций: `abs`, `min`, `max`.

Ограничения текущей итерации:
В данной версии языка **отсутствует поддержка переменных** и пользовательских функций. Программа представляет собой функцию `main`, содержащую последовательность инструкций, каждая из которых является либо вычислением выражения, либо операцией вывода. Ветвления, циклы, массивы и структуры запланированы для следующих итераций.

### Связь с другими языками
Синтаксис SharkSharp близок к языкам семейства C (блоки в фигурных скобках, инструкции разделяются точкой с запятой). Объявление функции использует формат, похожий на Go или TypeScript.

## Лексика

Раздел описывает лексические единицы (токены) языка SharkSharp и правила их выделения из текста программы. Лексер использует принцип максимального захвата: на каждом шаге выбирается самая длинная последовательность символов, образующая допустимый токен.

### Пробельные символы
Пробельные символы разделяют токены и в остальном не имеют значения: их количество и чередование не влияют на смысл программы. К пробельным символам относятся:
- Обычный пробел
- Горизонтальная табуляция (`\t`)
- Перевод строки (`\n`)
- Возврат каретки (`\r`)

### Комментарии
Поддерживаются два вида комментариев, которые лексер отбрасывает и не передаёт синтаксическому анализатору:
- Строчный: начинается с `//` и продолжается до конца строки.
- Блочный: начинается с `/*` и заканчивается на `*/`. Вложенные блочные комментарии не поддерживаются.

### Идентификаторы
Идентификатор начинается с латинской буквы или символа подчёркивания и может содержать латинские буквы, цифры и символы подчёркивания. Идентификаторы чувствительны к регистру (`sum` и `Sum` — разные имена). Идентификатор не может совпадать с ключевым словом.

### Ключевые слова
Зарезервированы и не могут использоваться как идентификаторы:

| Ключевое слово | Назначение |
| --- | --- |
| `int` | Целочисленный тип |
| `func` | Объявление функции |
| `return` | Возврат значения из функции (зарезервировано на будущее) |
| `true` | Логическая истина (зарезервировано на будущее) |
| `false` | Логическая ложь (зарезервировано на будущее) |

Имена `main`, `print`, `readInt`, `abs`, `min`, `max` ключевыми словами не являются. Это обычные идентификаторы, особый смысл которых определяется на этапе синтаксического и семантического анализа.

### Литералы
**Целочисленные литералы** (тип `int`) — последовательность десятичных цифр. Литерал не может начинаться с `0`, если он содержит более одной цифры (ведущие нули запрещены). Знак числа (минус) не входит в литерал и обрабатывается как унарный оператор.
Примеры: `0`, `42`, `9223372036854775807`.

### Операторы и знаки пунктуации

| Категория | Символы | Описание |
| --- | --- | --- |
| Арифметические | `+`, `-`, `*`, `/`, `%` | Сложение, вычитание, умножение, деление, остаток |
| Присваивание | `=` | Зарезервировано на будущее |
| Доступ и группировка | `.`, `[`, `]`, `(`, `)`, `{`, `}` | Скобки для вызова функций, блоков и группировки |
| Разделители | `,`, `;` | Разделитель аргументов, конец инструкции |

## Синтаксис и семантика текущей итерации

### Приоритет и ассоциативность операторов
Операторы с большим номером приоритета выполняются раньше. Операнды бинарных операций вычисляются слева направо.

| Приоритет | Оператор | Название | Ассоциативность |
| --- | --- | --- | --- |
| 1 (высший) | `-` (унарный) | Смена знака числа | Правая |
| 2 | `*`, `/`, `%` | Умножение, деление, остаток | Левая |
| 3 (низший) | `+`, `-` (бинарный) | Сложение, вычитание | Левая |

Круглые скобки `()` позволяют явно изменить порядок вычислений.

### Семантика вычислений
- Деление `/` выполняется нацело с отбрасыванием дробной части в сторону нуля (например, `7 / 2` равно `3`, `-7 / 2` равно `-3`).
- Остаток `%` имеет знак делимого (например, `-7 % 2` равно `-1`).
- Деление или взятие остатка при делителе, равном `0`, является ошибкой выполнения.
- Встроенная функция `print(x)` выводит десятичное представление числа `x` и перевод строки. Она не возвращает значения и может использоваться только как самостоятельная инструкция.
- Встроенная функция `readInt()` читает строку из стандартного ввода и возвращает целое число.
- Встроенные функции `abs(x)`, `min(x, y)`, `max(x, y)` возвращают модуль числа, минимум и максимум из двух чисел соответственно.

### Грамматика ISO EBNF
Грамматика описывает поток токенов лексера. Специальная последовательность `? IntLiteral ?` обозначает токен целочисленного литерала, описанный в разделе лексики. Терминалы записаны в двойных кавычках.

```ebnf
(* Программа и точка входа *)
program = main_function, end_of_file ;

main_function = "func", "main", "(", ")", block ;

block = "{", { statement }, "}" ;

(* Инструкции *)
statement = ( print_call | expression ), ";" ;

print_call = "print", "(", expression, ")" ;

(* Выражения: правила построены от низшего приоритета к высшему *)
expression = additive_expression ;

additive_expression = multiplicative_expression, 
    { ( "+" | "-" ), multiplicative_expression } ;

multiplicative_expression = unary_expression, 
    { ( "*" | "/" | "%" ), unary_expression } ;

unary_expression = "-", unary_expression 
                 | primary_expression ;

primary_expression = ? IntLiteral ?
                   | "(", expression, ")"
                   | function_call ;

(* Вызовы встроенных функций *)
function_call = identifier, "(", [ argument_list ], ")" ;

argument_list = expression, { ",", expression } ;

(* Мета-идентификаторы *)
identifier = ? идентификатор, описанный в разделе Лексика ? ;
end_of_file = ? признак конца входного потока токенов ? ;
```

### Лексические ошибки

К ошибкам лексического анализа относятся:

- Встречен символ, не входящий ни в один допустимый токен (вне комментариев), например `@`, `#`, `$`, `~`, одиночный `&` или `|`.
- Целочисленный литерал с ведущими нулями (например, `007`).
- Целочисленный литерал, значение которого выходит за допустимый диапазон 64-битного знакового целого.
- Буква или символ подчёркивания сразу после целочисленного литерала без пробела (например, `12abc`).
