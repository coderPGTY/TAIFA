# Спецификация языка SharkSharp

## Введение

SharkSharp — минималистичный императивный язык программирования общего назначения со строгой статической типизацией, разработанный для обучения основам построения компиляторов.

Ключевые особенности языка:

- Весь исходный код программы располагается в одном файле.
- Точкой входа является функция main.
- Строгая статическая типизация: встроенные типы int (64-битные знаковые целые числа), string (строки) и bool (логический тип). Неявные приведения типов запрещены.
- Императивный, процедурный стиль программирования.
- Арифметические (+, -, *, /, %), логические (&&, ||, !) и операторы сравнения (==, !=, <, <=, >, >=).
- Ввод/вывод осуществляется через встроенные функции print, read_int, read_string.
- Переменные объявляются явно с указанием типа.
- Поддержка структурного программирования: ветвление if/else, цикл while, последовательное выполнение инструкций в блоке.
- Поддержка одномерных массивов.
- Поддержка структур (записей) для группировки данных.

### Связь с другими языками

Синтаксис SharkSharp близок к языкам семейства C (блоки в фигурных скобках, инструкции разделяются точкой с запятой). При этом объявление переменных использует формат `имя: тип`, как в Pascal и TypeScript. Структуры по устройству близки к структурам C и Go — это простые записи без методов, что соответствует процедурному стилю языка.

## Лексика

Раздел описывает лексические единицы (токены) языка SharkSharp и правила их выделения из текста программы. Лексер использует принцип максимального захвата: на каждом шаге выбирается самая длинная последовательность символов, образующая допустимый токен.

### Пробельные символы

Пробельные символы разделяют токены и в остальном не имеют значения: их количество и чередование не влияют на смысл программы. К пробельным символам относятся:

- Обычный пробел
- Горизонтальная табуляция (`\t`)
- Перевод строки (`\n`)
- Возврат каретки (`\r`)

### Комментарии

Поддерживаются два вида комментариев, которые лексер отбрасывает и не передаёт синтаксическому анализатору:

| Вид | Синтаксис | Пример |
| --- | --- | --- |
| Строчный | `// текст` | `// это комментарий` |
| Блочный | `/* текст */` | `/* блок */` |

Строчный комментарий заканчивается ближайшим концом строки. Блочные комментарии не поддерживают вложенность: первая встретившаяся последовательность `*/` завершает комментарий.

### Идентификаторы

Идентификатор начинается с латинской буквы или символа подчёркивания и может содержать латинские буквы, цифры и символы подчёркивания. Идентификаторы чувствительны к регистру (`sum` и `Sum` — разные имена). Идентификатор не может совпадать с ключевым словом.

### Ключевые слова

Зарезервированы и не могут использоваться как идентификаторы:

| Ключевое слово | Назначение |
| --- | --- |
| `int` | Знаковый целочисленный тип |
| `string` | Строковый тип |
| `bool` | Логический тип |
| `struct` | Объявление структуры |
| `let` | Объявление переменной |
| `func` | Объявление функции |
| `return` | Возврат значения из функции |
| `if` | Условный оператор |
| `else` | Альтернативная ветвь условия |
| `while` | Цикл с предусловием |
| `true` | Логическая истина |
| `false` | Логическая ложь |

Имя `main` ключевым словом не является — это обычный идентификатор, который по соглашению обозначает функцию, являющуюся точкой входа в программу.

### Литералы

**Целочисленные литералы** (тип `int`) — последовательность десятичных цифр. Литерал не может начинаться с `0`, если он содержит более одной цифры (ведущие нули запрещены). Знак числа (минус) не входит в литерал и обрабатывается как унарный оператор.

Примеры: `0`, `42`, `9223372036854775807`.

**Строковые литералы** (тип `string`) — последовательность символов в двойных кавычках. Поддерживаются следующие escape-последовательности:

| Последовательность | Значение |
| --- | --- |
| `\n` | Перенос строки |
| `\t` | Горизонтальная табуляция |
| `\"` | Двойная кавычка |
| `\\` | Обратная косая черта |

Символы перевода строки без экранирования внутри литерала недопустимы.

Примеры: `"hello"`, `"shark\n"`, `"escape \"quote\""`.

**Логические литералы** (тип `bool`) — ключевые слова `true` и `false`.

### Операторы и знаки пунктуации

| Категория | Символы | Описание |
| --- | --- | --- |
| Арифметические | `+`, `-`, `*`, `/`, `%` | Сложение, вычитание, умножение, деление, остаток |
| Сравнения | `==`, `!=`, `<`, `<=`, `>`, `>=` | Равно, не равно, меньше, меньше или равно, больше, больше или равно |
| Логические | `&&`, `\|\|`, `!` | Логическое И, логическое ИЛИ, логическое НЕ |
| Присваивание | `=` | Присвоить значение |
| Доступ и индексация | `.`, `[`, `]` | Доступ к полю, доступ к элементу массива |
| Группировка и блоки | `(`, `)`, `{`, `}` | Группировка выражений, блоки кода |
| Разделители | `,`, `;`, `:` | Разделитель параметров, конец инструкции, объявление типа |

Символы `&` и `|` по отдельности токенами не являются и допустимы только в составе `&&` и `||`.

### Лексические ошибки

К ошибкам лексического анализа относятся:

- Встречен символ, не входящий ни в один токен (вне комментариев и строк), например `@`, `#`, `$`, `~`.
- Незакрытый строковый литерал: до закрывающей кавычки встретился конец строки или файла.
- Неизвестная escape-последовательность в строковом литерале (например `\q`).
- Незакрытый блочный комментарий: до последовательности `*/` встретился конец файла.
- Целочисленный литерал с ведущими нулями (например `007`).
